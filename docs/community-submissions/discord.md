# Discord post

```text
I made a DSH plugin for a problem I kept hitting in long agent sessions: a side question about an old answer would contaminate the main task, while a normal sidebar thread was still just one more linear conversation.

dsh-nested-followups lets you keep branching from any completed answer at any depth, with no plugin-defined nesting limit. Every level is a real isolated session. The main chat stays untouched, branch tools are read-only, and Tree View keeps the recursive trail attached to the root conversation.

13-second real DSH demo + install: https://github.com/sluminositys/dsh-nested-followups
```
