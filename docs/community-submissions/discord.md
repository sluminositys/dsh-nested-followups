# Discord post

```text
I made a small DSH plugin for a problem I kept hitting in long agent sessions: asking one side question about an old answer would contaminate the rest of the main task.

dsh-nested-followups lets you branch from any completed answer into a real isolated session, continue inside that branch, and branch again at any depth. The main chat stays linear, branch tools are read-only, and everything remains attached to the root conversation in one Tree View.

13-second real DSH demo + install: https://github.com/sluminositys/dsh-nested-followups
```
